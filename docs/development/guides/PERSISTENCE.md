## 数据覆盖 / Data Coverage

设备的 16 MiB flash 不等于单个固件容量：`ota_0`、`ota_1` 各为 `0x500000`（5 MiB），分别位于 `0x10000`、`0x510000`；`storage` 是 `0xA10000` 起的 `0x5E8000` 内部 FAT，`nvs` 是 `0xFF8000` 起的 32 KiB。这些是布局事实，活动槽必须当次读取。
The device has 16 MiB of flash but each OTA slot holds 5 MiB. Internal FAT and tail NVS are separate data partitions; the active slot must be read for each operation.

恢复先在当前 NVS 的 RAM 副本上按实际页布局试写设置、历史、分类选择、WiFi 和天气。常规顺序写不下时，跳过尚不存在且等同开机默认值的偏好，并先替换备份覆盖的历史；仍写不下则在更改原资料前提示「机内配置空间不足」。仅有需要恢复的手账或匹配书库的分类快照时才要求内部 FAT 可挂载，不格式化。TF 备份格式和分区不变。容量预检不等于跨介质事务：恢复中仍不可拔卡或断电。
[RAM 预检适配层](../../../components/restore_nvs/restore_nvs.cpp)只读取实际分区；升级固定的 ESP-IDF v6.1 时须复核其页分配接口。
Restore rehearses all NVS writes on an in-memory copy using the actual page allocator. Under pressure it omits absent boot defaults and may replace the covered history first; a capacity rejection leaves live data untouched. Internal FAT is required only for applicable journal or folder snapshots and is never formatted by restore. The backup format and partition layout are unchanged. This is not a cross-media transaction: do not remove the card or cut power during restore.

若备份提示「书签损坏」，上次成功的备份不被替换。可在电脑上先完整复制 TF 卡的 `.readpico` 隐藏目录，再从 `.readpico/bookmarks/` 移出提示的文件及同名 `.bak`/`.tmp` 副本（保留原件供修复），重新备份其余书签。不要直接删除整个目录。若经历过中断的配置恢复，当前记录也可能暂存在同级的 `bookmarks.old` 中。/ If backup identifies a corrupt bookmark, the last successful backup remains unchanged. Copy the hidden `.readpico` directory, then move only the named bookmark and its sibling rollback/temp files aside before retrying. Keep the originals for recovery; never delete the whole directory. After an interrupted restore the active copy may be in `bookmarks.old`.

便签本使用书架样式编号 6；包含该样式的 v49 备份需要支持便签本的固件，旧固件降级恢复须使用旧固件已保存的兼容备份。/ Notepad uses shelf style ID 6; a v49 backup containing it requires notepad-capable firmware. Before downgrading, retain a compatible backup made on the older firmware.

v48–v52 恢复先校验数据和 WiFi 容量再写入，**不是跨卷回滚事务**。手账为快照替换。备份含明文 WiFi 密码；请妥善保管。要还原实际书架，必须另存 `books/` 目录树（含空目录）和原书。

v48–v52 validate data and WiFi capacity before writing; later I/O can still fail across stores. Journal snapshots replace rather than merge. Protect plaintext WiFi credentials. Back up the actual `books/` tree, including empty folders, separately.

手势操作写入 `read_pico/fs_gestures`（bit 0 开关，bits 1–2 为窄／标准／宽；合法值 0–5，缺省 3）。v52 备份携带该字节与反码，先校验后恢复；v51 及以前不改本机手势偏好。/ Gesture controls store enablement and edge width together. Backup v52 validates the byte and its complement before applying changes; older backups preserve the local preference.

按键「返回」使用新动作编号 10；旧试验编号 7 仍保留不用。包含新绑定的配置备份须由支持该动作的固件恢复。/ One-level Back uses new action ID 10; retired ID 7 remains reserved. Backups containing this binding require compatible firmware.
